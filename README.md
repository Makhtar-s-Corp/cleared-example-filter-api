# Filter API, the second demo project of Cleared v2

A small HTTP API (`POST /check`, `GET /health`) that the guestbook consumes to filter words. It is the second service of the multi-service proof of Cleared v2 milestone 2 (`docs/v2/milestone-2-plan.md` in the Cleared repository, lane 28). The code is seeded from `examples/filter-api/` in the Cleared repository.
